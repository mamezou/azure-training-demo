## デモの特徴

AZ-400のデモは、実践的なDevOpsプラクティスに焦点を当てています：

- CI/CDパイプラインの構築と運用
- Infrastructure as Codeの実装
- セキュリティとコンプライアンス
- 継続的なモニタリングとフィードバック

## 事前準備

デモを実施する前に、以下を準備してください：

1. Azure DevOps組織またはGitHubアカウント
2. サンプルアプリケーションコード
3. Azureサブスクリプション
4. 必要な権限とアクセス

## デモの進め方

1. **概念の説明**: DevOpsプラクティスの概念を説明
2. **ライブデモ**: 実際にパイプラインを作成・実行
3. **結果の確認**: ビルド、テスト、デプロイの結果を確認
4. **ハンズオン**: 受講者が自分で実装（時間があれば）

## 実施時の注意事項

- パイプラインの実行には時間がかかります。待ち時間を活用して説明を行いましょう
- エラーが発生した場合のトラブルシューティングも学習の機会です
- セキュリティに関する設定（シークレット、認証情報など）は特に注意して説明してください
- 実際の開発チームでの運用を想定した現実的なシナリオを提示しましょう
