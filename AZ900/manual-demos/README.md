## デモの実施方法

### 準備

1. Azureポータル (https://portal.azure.com) にアクセス
2. 検証用サブスクリプションでログイン
3. デモに必要な権限を確認（通常は共同作成者ロール以上）

### デモ実施時のポイント

- **事前準備**: デモ前に手順を一通り実行して動作確認
- **説明しながら実施**: 各ステップで何をしているか説明
- **受講者の理解度確認**: 適宜質問を受け付ける
- **時間管理**: 予定時間内に収まるよう調整

### デモ後のクリーンアップ

- 作成したリソースは必ず削除
- リソースグループごと削除すると効率的
- コストが発生していないことを確認

## 手順書の読み方

各手順書は以下の構成になっています：

- **概要**: デモの目的と学習内容
- **前提条件**: 必要な権限やリソース
- **所要時間**: 想定される実施時間
- **手順**: ステップバイステップの操作手順
- **確認事項**: 正しく実行できたかの確認方法
- **クリーンアップ**: リソースの削除手順
- **補足説明**: 関連する概念やベストプラクティス

## カスタマイズ

手順書はトレーニングの進行や受講者のレベルに応じてカスタマイズできます：

- 基礎レベル: 全手順を詳細に説明
- 中級レベル: 一部の手順を受講者に実施させる
- 上級レベル: 要件だけ伝えて自由に実装させる
