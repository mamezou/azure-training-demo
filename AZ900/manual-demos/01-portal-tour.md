# Azureポータルツアー

## 概要

このデモでは、Azureポータルの基本的な画面構成と操作方法を学びます。
Azure初学者にとって、ポータルに慣れることは重要な第一歩です。

## 学習目標

- Azureポータルの基本的なナビゲーション
- 主要なメニューと機能の場所
- リソースの検索方法
- ダッシュボードのカスタマイズ
- Cloud Shellの使用方法

## 前提条件

- Azureアカウント
- ブラウザ（Chrome、Edge、Firefox、Safari推奨）
- インターネット接続

## 所要時間

約10分

## 手順

### ステップ 1: Azureポータルへのアクセス

1. ブラウザで https://portal.azure.com にアクセス
2. Azureアカウントでサインイン
3. 多要素認証（MFA）が有効な場合は、追加の認証を実施

### ステップ 2: ポータルのメイン画面を確認

ポータルにログインすると、以下の主要な要素が表示されます：

#### 左側のナビゲーションメニュー
- **ホーム**: ポータルのホーム画面
- **ダッシュボード**: カスタマイズ可能なダッシュボード
- **すべてのサービス**: Azure の全サービス一覧
- **リソースグループ**: リソースの論理的なグループ
- **すべてのリソース**: サブスクリプション内の全リソース

#### 上部のツールバー
- **検索バー**: リソースやサービスを検索
- **Cloud Shell**: ブラウザ内でAzure CLIまたはPowerShellを実行
- **通知**: アクティビティとアラート
- **設定**: ポータルの設定
- **ヘルプ**: ドキュメントとサポート
- **ディレクトリ + サブスクリプション**: テナントとサブスクリプションの切り替え
- **アカウント**: プロフィールとサインアウト

### ステップ 3: サービスの検索

1. 上部の検索バーをクリック
2. 「仮想マシン」と入力
3. 検索結果から「仮想マシン」サービスを選択
4. サービスのページが表示されることを確認

**ポイント**: 検索は最も効率的なナビゲーション方法です。

### ステップ 4: すべてのサービスを確認

1. 左側メニューから「すべてのサービス」をクリック
2. カテゴリごとにサービスが整理されていることを確認
   - **コンピューティング**: VM、App Service、Functionsなど
   - **ネットワーク**: Virtual Network、Load Balancerなど
   - **ストレージ**: Storage Account、Backupなど
   - **データベース**: SQL Database、Cosmos DBなど
3. 気に入ったサービスの横にある星マークをクリックして「お気に入り」に追加

### ステップ 5: ダッシュボードのカスタマイズ

1. 左側メニューから「ダッシュボード」をクリック
2. 上部の「+ 新しいダッシュボード」をクリック
3. ダッシュボード名を「AZ-900 Demo」に変更
4. 「カスタマイズが完了しました」をクリック
5. タイルギャラリーから「Clock」タイルをドラッグ&ドロップ
6. 「保存」をクリック

**ポイント**: ダッシュボードは複数作成でき、プロジェクトや環境ごとに整理できます。

### ステップ 6: Cloud Shellの起動

1. 上部ツールバーの「Cloud Shell」アイコン（>_）をクリック
2. 初回起動の場合：
   - 「Bashの開始」または「PowerShellの開始」を選択
   - ストレージアカウントの作成を求められたら「ストレージの作成」をクリック
3. Cloud Shellが起動したら、以下のコマンドを実行：

```bash
# Azure CLIのバージョン確認
az --version

# サブスクリプション情報の表示
az account show

# リソースグループ一覧の表示
az group list --output table
```

4. Cloud Shellを閉じるには、右上の「×」をクリック

### ステップ 7: リソースグループの確認

1. 左側メニューまたは検索から「リソースグループ」にアクセス
2. 既存のリソースグループがあれば一覧表示される
3. いずれかのリソースグループをクリックして詳細を確認
   - **概要**: リソースグループ内のリソース
   - **アクティビティログ**: 操作履歴
   - **アクセス制御 (IAM)**: 権限管理
   - **タグ**: メタデータの管理

### ステップ 8: Azure Advisorの確認

1. 検索バーで「Advisor」を検索
2. Azure Advisorを開く
3. 推奨事項を確認：
   - **コスト**: コスト削減の推奨事項
   - **セキュリティ**: セキュリティの改善案
   - **信頼性**: 可用性の向上
   - **パフォーマンス**: パフォーマンスの最適化
   - **オペレーショナルエクセレンス**: 運用の改善

### ステップ 9: Cost Management + Billing

1. 検索バーで「Cost Management」を検索
2. 「コスト管理 + 請求」を開く
3. 「コスト分析」で現在のコストを確認
4. 「予算」でコストアラートを設定できることを確認

## 確認事項

以下ができることを確認してください：

- ✅ Azureポータルにアクセスできる
- ✅ サービスを検索できる
- ✅ ダッシュボードをカスタマイズできる
- ✅ Cloud Shellを起動できる
- ✅ リソースグループにアクセスできる

## クリーンアップ

このデモでは新しいリソースを作成していないため、特にクリーンアップは不要です。

## 補足説明

### Azureポータルのショートカット

- **G + N**: 通知パネルを開く
- **G + /**: 検索にフォーカス
- **G + ,**: 設定を開く

### モバイルアプリ

Azureポータルはモバイルアプリも提供しています：
- iOS: App Store から「Microsoft Azure」をダウンロード
- Android: Google Play から「Microsoft Azure」をダウンロード

### ポータルの言語変更

1. 右上の歯車アイコン（設定）をクリック
2. 「言語 + リージョン」を選択
3. 希望の言語を選択
4. 「適用」をクリック

### ダークモード

1. 設定アイコンをクリック
2. 「外観 + スタートアップビュー」を選択
3. 「ダーク」を選択
