## デモの特徴

AZ-305のデモは、アーキテクチャ設計に重点を置いています：

- 要件定義から設計へのアプローチ
- トレードオフの考慮と意思決定
- Azure Well-Architected Frameworkの適用
- 実装可能な設計の作成

## デモの進め方

1. **要件の提示**: ビジネス要件と技術要件を提示
2. **設計の検討**: 受講者とともにアーキテクチャを検討
3. **設計図の作成**: ホワイトボードまたはツールで図を作成
4. **レビューと改善**: 設計をレビューし、改善点を議論

## 推奨ツール

- Azure アーキテクチャ図作成: Visio、draw.io、Lucidchart
- コスト見積もり: Azure Pricing Calculator
- アーキテクチャレビュー: Azure Well-Architected Review

## 実施時の注意事項

- アーキテクチャ設計は正解が一つではありません。複数の選択肢を提示しましょう
- トレードオフを明確にし、なぜその選択をしたかを説明してください
- 受講者の意見を積極的に取り入れ、議論を促進してください
